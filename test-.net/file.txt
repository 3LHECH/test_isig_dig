The scaffolder fails because aspnet-codegenerator defaults to expecting SQL Server packages installed, even when using SQLite.

Pass the -sqlite flag explicitly so it uses your SQLite DbContext provider.


dotnet aspnet-codegenerator controller -name ProductsController -async -api -m Product -dc test_.net.Data.ApplicationDbContext -outDir Controllers -sqlite
